# FM Data public landing — redesign

Rebuilt after the user's rejection of the previous direction, using UI UX Pro Max from https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.

The skill was installed at `C:/Users/syakir/.codex/skills/ui-ux-pro-max`. Its `banking financial services` design-system search returned Minimalism & Swiss Style and IBM Plex Sans. The first broader query returned Apple-oriented liquid glass and luxury retail typography and was rejected as a poor product fit.

The new direction uses architectural imagery, a strong sans-serif hierarchy, rectangular controls and a full-width photographic opening. White sections carry the module directory; navy separates team responsibilities. Suggested gold accents, sales forms and unverifiable proof were not adopted. The architecture is a generated fictional scene, not a bank headquarters or partner endorsement. The folder and record diagram are conceptual illustrations, without live financial data.

The photo moves slowly, with pause control, offscreen/hidden-page pausing and reduced-motion support. Native details elements expose five capability groups. Team tabs support arrow keys, Home and End. Mobile navigation can be dismissed with Escape.

## Integration

The public HTML, CSS, JavaScript and image are isolated from the dashboard. Existing sign-in links and the signed-out application redirect remain in place. No backend data changes.
